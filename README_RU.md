# ScreenStudy для MacBook M5

Боковое окно, которое читает выбранную область экрана и предлагает ответы с объяснениями. Создано для macOS 14+ на Apple Silicon. Это исходный проект с установщиком: INSTALL.command собирает обычное приложение ScreenStudy.app непосредственно на вашем Mac.

## Новое в 1.3.0: сопоставление и ключевые слова

- Задания с перетаскиванием показываются как пары **что перенести → куда перенести**. Одинаковые номера рядом с элементами на экране обозначают пару.
- В заданиях на выделение слов показываются **точные цитаты для каждого абзаца**. Номера возле строк связывают их с фразами в карточке; они не означают выделение всей строки.
- Все пары или шесть абзацев под общей инструкцией считаются одним заданием. Настройку «Вопросов за запрос» можно оставить равной 1.
- Выделите область целиком, вместе с инструкцией и обеими колонками/всеми абзацами. Для сложной раскладки включите **С изображением** у модели с поддержкой изображений.
- Когда ответ готов, нажмите **Закрепить вопрос**, чтобы перетаскивание карточек или выделение слов не запускало новые автоматические запросы.
- Значок **i** объясняет пары и ключевые фразы. Перетаскивание и нажатия на слова выполняются вами; приложение показывает решение.
- Цитаты проверяются по распознанному тексту. Не найденные цитаты скрываются с предупреждением, неоднозначные позиции не отмечаются. Если OCR ошибся, увеличьте масштаб страницы и повторите запрос.
- При явной ссылке на предыдущий вопрос модель получает один предыдущий ответ (до 2800 символов вопроса и ответа), если он есть. Он не считается проверенным фактом; если контекста нет, приложение сообщает об этом. **Очистить** удаляет контекст. Объяснение показывает, какой предыдущий ответ использовался.
- Первичное решение — один запрос. Для составных заданий быстрый режим API/Ollama разрешает ответ минимум до 4096 токенов; фактический расход зависит от длины ответа. Настройки подписки ChatGPT управляются её провайдером.

## Новое в 1.2.1: ответ больше не исчезает от движения мыши

- Последний ответ, ручные правки и кнопка объяснения остаются в боковой карточке при изменениях страницы. Карточка заменяется, когда готов ответ на новое задание; если заданий не найдено или запрос завершился ошибкой, прежняя карточка остаётся с соответствующим статусом.
- При сравнении задания учитывается текст без лишних пробелов и мелких сдвигов OCR, а также структура изображения с допуском на небольшие визуальные изменения. Изменение числа, оператора или отрицания не игнорируется. Курсор не захватывается.
- Новое состояние подтверждается тремя наблюдениями и выдержкой не менее 0,55 с. При штатном опросе раз в 400 мс это обычно около 0,8 с плюс время захвата/OCR. Кратковременная подсказка не отменяет уже выполняющийся ответ.
- **Закрепить вопрос** сохраняет карточку и блокирует автоматические запросы новых заданий. Экран проверяется локально для правильного положения меток. Объяснение и переписывание по нажатию по-прежнему могут отправлять отдельный запрос. Уже отправленный запрос может завершиться у провайдера, но не заменит закреплённый ответ.
- **Следующий вопрос →** снимает закрепление и возобновляет автоматическое наблюдение. Предыдущая карточка остаётся до готовности новой.
- При прокрутке метки скрываются сразу. После стабилизации они возвращаются, если строки и положение можно сопоставить однозначно; иначе остаются скрыты до нового анализа. Кнопка объяснения в боковой карточке доступна в любом случае.
- Объяснение всегда получает исходный снимок показанного ответа. Возврат к последнему отвеченному заданию не вызывает повторный автоматический запрос. Разовый запрос отвечает на зафиксированный снимок, даже если вы затем передвинули мышь или открыли другую страницу.

Для обновления закройте приложение через **⌘Q**, распакуйте новый архив и запустите **INSTALL.command**. Проверьте версию **1.3.0** в заголовке. Настройки подключения сохраняются.

Сравнение изображений имеет порог чувствительности: очень мелкая графическая правка может быть пропущена. Если изменился рисунок, а нового ответа нет, используйте **Ответить сейчас** (в закреплённом режиме сначала **Следующий вопрос**). Выделяйте один вопрос без часов, видео и посторонних всплывающих элементов.

## Подключение через подписку ChatGPT (с версии 1.2.0)

В настройках появился режим **ChatGPT · моя подписка**. Вход открывается в обычном браузере на вашем Mac. При доступности этой функции для аккаунта ответы используют подписку ChatGPT или доступные кредиты. API-ключ не нужен. Это отдельное подключение модели: история этого чата в ScreenStudy не переносится.

1. Закройте старую ScreenStudy через **⌘Q**, распакуйте архив и запустите **INSTALL.command** из новой папки. В заголовке появится версия **1.3.0**.
2. Нажмите **⚙ → Режим → ChatGPT · моя подписка**.
3. Нажмите **Войти через ChatGPT / выбрать модель**, затем **Continue with ChatGPT**.
4. В браузере войдите в нужный аккаунт, выберите пространство, если предложено, и разрешите ScreenStudy использовать подписку. Окно приложения ждёт вход до 3 минут; вход можно отменить.
5. Вернитесь в приложение. Список моделей загружается из вашего аккаунта. Выберите модель → **Использовать подписку**.
6. Нажмите **Проверить подключение**. Эта кнопка отправляет один короткий запрос и тоже использует подписку. Успешный вход и список моделей сами по себе ещё не подтверждают возможность получить ответ.
7. Нажмите **Сохранить**, выберите область с одним вопросом и нажмите **Ответить сейчас** или **Наблюдать**. Для формул и рисунков включите изображение; выбранная модель должна поддерживать картинки.

В главном окне и окне подключения есть **Использование ChatGPT** — открывает https://chatgpt.com/settings/usage. Лимиты подписки и приложения сохраняются. При недоступности подписки или исчерпании лимита наблюдение приостанавливается. Автоматического переключения на платный API или другой аккаунт нет.

Для другого аккаунта откройте то же окно подключения и выберите **Добавить аккаунт ChatGPT…**. Сохранённые подключения различаются адресом и коротким идентификатором; для каждого загружается свой список моделей. Кнопка **Выйти** удаляет локальные токены выбранного подключения и запрашивает отзыв сеанса на сервере. Если сервер недоступен, приложение сообщает, что отзыв не подтверждён; отключите ScreenStudy в настройках ChatGPT.

**Хранение:** идентификатор установки находится в `~/Library/Application Support/ScreenStudy/chatgpt-host.json`, подключения — в `chatgpt-accounts.json` в той же папке. Каталог имеет права 0700, файлы — 0600. Токены обновляются автоматически; не передавайте эти файлы другим людям. При выходе сохраняется только регистрация аккаунта для повторного входа. Снимки и ответы по-прежнему не сохраняются приложением на диск.

**Что проверено:** локальный имитатор входа, проверка подписи, отказ в разрешении, обновление сеанса, выбор аккаунта/модели, ошибки подписки, обрыв потока и интерфейс. **Реальный вход OpenAI, право вашего аккаунта использовать подписку, ответы настоящей модели и macOS-сборка здесь не проверены.** Первую реальную проверку выполните шагом 6. Скорость зависит от выбранной модели и задачи; ускорение относительно Groq не заявляется.

Реализация следует официальной документации OpenAI, проверенной 17.10.2026:

- https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference
- https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions

## Исправление подключения 1.1.1

HTTP 403 означает отказ в доступе. По одной строке 403 нельзя определить причину: она может находиться в правах на модель или в защите API.

В версии 1.1.1 запросы содержат явный User-Agent ScreenStudy/1.1.1. Приложение показывает сообщение и код ошибки, которые передал сервер, вместо одной общей фразы. API-ключ маскируется в тексте ошибки; HTML-страницы отказа полностью не выводятся. Автоматических повторов и обхода ограничений аккаунта нет.

Обновление: закройте ScreenStudy через ⌘Q, распакуйте новый архив, откройте INSTALL.command. Затем нажмите ⚙ → Проверить подключение. Поле результата можно выделить и скопировать. Если ошибка осталась, передайте текст из этого поля. Код model_permission_blocked_org/project указывает на ограничение модели в настройках организации/проекта Groq; код 1010 — на отклонение HTTP-клиента защитой Cloudflare. Доступ к аккаунту и реальная причина отказа у пользователя в этой среде не проверялись.

## Обновление 1.1: быстрый Groq

1. Полностью закройте старую ScreenStudy через ⌘Q. Распакуйте новый архив в отдельную папку и запустите **INSTALL.command**. Он пересоберёт приложение и сохранит предыдущую .app как резервную копию. Пользовательские настройки остаются на месте.
2. Создайте свой API-ключ: https://console.groq.com/keys . Ключ нужен именно от Groq. В чат его отправлять не нужно.
3. Откройте **⚙ → Groq · быстрый облачный режим**. Адрес `https://api.groq.com/openai/v1` и модель `qwen/qwen3.8-27b` уже заполнены. Вставьте ключ, нажмите **Проверить подключение → Сохранить**.
4. Выделите **один вопрос целиком** вместе с вариантами. Оставьте **Быстро**. Для обычного текста выключите **С изображением**; для формул, схем и рисунков включите эту галочку в главном окне. Смена этих настроек ставит наблюдение на паузу: затем нажмите **Ответить сейчас** или **Наблюдать**.
5. В строке под статусом видны время чтения экрана/OCR, время запроса к ИИ и общее время от начала первого снимка этого вопроса, включая ожидание неподвижного кадра. Это измерения на вашем Mac, а не заранее заданные цифры.

Что изменилось:
- Готовый профиль Groq. В режиме **Быстро** у Qwen отключено длительное рассуждение (`reasoning_effort=none`); **Подумать точнее** включает стандартное рассуждение. Быстрый режим может быть менее точным на сложных задачах.
- Первый ответ приходит без объяснения. Объяснение запрашивается отдельно по **i**, затем остаётся в памяти для этой карточки. Открытие объяснения ставит наблюдение на паузу.
- По умолчанию решается один вопрос. До восьми можно выбрать в настройках — это потребует больше времени и токенов. При нескольких вопросах на экране для первого запроса берётся первый полностью видимый; выделение области позволяет выбрать нужный.
- Интервал опроса сокращён с 1000 до 400 мс. По-прежнему нужны два одинаковых наблюдения; если захват ещё выполняется, новый не запускается.
- Профиль Groq устанавливает минимум 1 с между началами запросов вместо прежних 6 с. Неподвижный вопрос повторно не отправляется. Старые настройки Ollama сохраняются до выбора нового профиля.
- Для неизменившихся пикселей выбранной области повторный OCR пропускается. В текстовом режиме JPEG для отправки не кодируется. Координаты OCR не передаются модели; они остаются в приложении для меток.
- Таймаут быстрого Groq — 45 с, других режимов — 150 с. При ошибке или лимите наблюдение останавливается; скрытых платных повторов нет. Уже отправленный запрос может завершиться у провайдера даже после паузы.

Модель Groq имеет статус **Preview**. Доступность и бесплатные лимиты зависят от аккаунта. Приложение само не включает платный тариф и не пополняет баланс; при использовании ключа платного аккаунта запросы тарифицируются его провайдером. Установка и тест подключения не измеряют точность или полную скорость решения заданий.

Тест для сравнения: выберите один и тот же неподвижный вопрос, нажмите «Ответить сейчас» в старом/локальном режиме и в Groq. Сравните время ИИ и правильность ответа. Затем проверьте вопрос с формулой при включённом изображении. Не меняйте страницу до завершения запроса.

## Быстрый запуск

1. Распакуйте архив целиком. Откройте **INSTALL.command**. Если macOS не позволяет открыть файл двойным щелчком, откройте Терминал, напишите `bash ` с пробелом, перетащите INSTALL.command в окно Терминала и нажмите Enter.
2. Если установщик попросит Python, установите **Python 3.13, macOS universal2** с https://www.python.org/downloads/macos/ и повторите пункт 1. Поддерживаются Python 3.10–3.13. Python 3.14 этой сборке не подходит. Не запускайте Терминал через Rosetta.
3. Дождитесь установки компонентов и сборки. Приложение появится в **домашней папке → Applications → ScreenStudy.app** и откроется. Права администратора не нужны. При первом запуске установки нужен интернет; компоненты занимают несколько сотен МБ. Полный Xcode не требуется, но PyInstaller может попросить Command Line Tools — тогда выполните `xcode-select --install` и повторите установку.
4. Выберите локальную или облачную ИИ по инструкции ниже. Нажмите **⚙ → Проверить подключение → Сохранить**.
5. Откройте задание. В ScreenStudy нажмите **Область…** и разрешите запись экрана. После выдачи разрешения полностью закройте и заново откройте приложение.
6. Ещё раз нажмите **Область…**, обведите вопрос **вместе с вариантами, рисунками и необходимым контекстом**, затем Enter. Нажмите **Наблюдать**.

В следующий раз достаточно открыть ScreenStudy.app через Spotlight/Finder или файл START.command. Исходную папку после успешной установки можно переместить: собранное приложение содержит собственный Python и зависимости.

## Локально, без облачного API

1. Установите Ollama: https://ollama.com/download/mac . Откройте приложение.
2. Запустите **SETUP_LOCAL_AI.command**. Он загрузит модель **qwen3-vl:4b**. Сам файл модели занимает примерно 3,3 ГБ; для работы потребуется дополнительная оперативная память.
3. В ScreenStudy выберите:
   - режим **Ollama · на этом Mac**;
   - адрес `http://127.0.0.1:11434`;
   - модель `qwen3-vl:4b`;
   - API-ключ оставьте пустым;
   - передачу изображения оставьте включённой.
4. Нажмите **Проверить подключение**. Первая загрузка модели в память может занять заметное время.

После загрузки модели этот режим работает без интернета; приложение отправляет данные только Ollama на этом Mac. Если памяти мало, загрузите в Терминале `ollama pull qwen3-vl:2b` и укажите `qwen3-vl:2b` в настройках. Качество и скорость зависят от модели, объёма памяти, размера области и задачи. Сам по себе чип M5 не гарантирует мгновенный ответ. Модель не следует выбирать по скорости без проверки качества на ваших заданиях.

## Облачная ИИ

Поддерживается API формата **Chat Completions**, включая передачу изображений для vision-моделей. В режиме «Облачный / совместимый API» введите адрес, точное имя доступной вам модели и её API-ключ.

Примеры адресов:

| Провайдер | Адрес в настройках |
|---|---|
| Groq, готовый профиль | `https://api.groq.com/openai/v1` |
| Gemini, совместимый API | `https://generativelanguage.googleapis.com/v1beta/openai` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Локальный совместимый сервер | `http://localhost:1234/v1` |

Приложение само добавляет `/chat/completions`. Не вставляйте этот суффикс ещё раз. Модель выбирайте из кабинета вашего провайдера; нужен ввод изображений, если соответствующая галочка включена. Поддержка каждого стороннего провайдера отдельно не проверялась. Приложение не подключается к сайту чата по подписке: нужны доступ и ключ именно к API. Использование облачного API может оплачиваться отдельно.

Если модель принимает только текст, отключите **Передавать изображение области**. Тогда OCR выполнится на Mac, а в API уйдут только распознанные строки с координатами. Это хуже подходит для схем, рисунков и сложных формул.

Ключ по умолчанию хранится только до закрытия приложения. По желанию включите сохранение в **Связке ключей macOS**. В settings.json ключ не записывается. При ручном изменении адреса поле ключа очищается, чтобы случайно не отправить старый ключ другому сервису.

## Как пользоваться

- **Наблюдать**: новый снимок запрашивается каждые 400 мс, если предыдущий захват завершился. После трёх устойчивых наблюдений и выдержки не менее 0,55 с приложение отправляет новое задание ИИ; мелкие изменения оформления фильтруются. Одновременно выполняется один запрос. Минимальный интервал между запросами для новых настроек и профиля Groq — 1 секунда; его можно изменить. Это частота проверки и ограничения отправки, а не обещание ответа за 1 секунду.
- **Ответить сейчас**: один запрос по текущему снимку, без ожидания стабилизации. Запрос привязан к исходному снимку: последующее движение мыши или смена страницы не отменяют этот ответ. После получения ответа наблюдение прекращается; поверх исходного экрана в этом режиме метки не рисуются.
- **Пауза**: прекращает новые снимки и запросы, убирает метки. Уже отправленный запрос сервис может завершить и тарифицировать; его запоздавший ответ не применяется.
- **Галочки**: рекомендуемые варианты показаны в карточке. В режиме наблюдения они также появляются возле исходных строк, если OCR и ИИ сопоставили их. Приложение не нажимает варианты за вас. При смене экрана старые метки снимаются на следующей проверке, с задержкой текущего захвата и интервала опроса; до этого возможна короткая задержка.
- **i рядом с вопросом**: открывает формулировку и ответ, а затем запрашивает пояснение и обоснование. Повторное открытие использует уже полученное объяснение; наблюдение остаётся на паузе. При доступных координатах такой значок появляется также возле вопроса на исходном экране.
- **Редактирование**: готовый ответ в карточке можно менять вручную.
- **Переписать ответ…**: опишите изменение, например «короче», «объясни проще», «одним абзацем». Наблюдение приостанавливается, чтобы новый снимок не затёр редактируемый ответ. Исходное объяснение остаётся объяснением первоначального решения.
- **Копировать**: копирует текущий текст ответа. Вставьте его вручную через ⌘V.
- **Вставить · 3 с**: копирует текст и начинает отсчёт. За это время нажмите в нужное поле другого приложения. Если требуется заменить существующий текст, сначала выделите его. После отсчёта приложение отправляет ⌘V. Кнопка **Отменить вставку** отменяет действие. Если буфер обмена изменился или активным осталось ScreenStudy, автоматическая вставка отменяется. Приложение не нажимает Enter и не отправляет форму.
- **Показать экран**: расширяет окно и показывает последние снимки выбранной области рядом с ответами. Зелёная кнопка окна macOS позволяет перейти в полноэкранный режим. Просмотр обновляется по завершении очередного захвата (интервал опроса 400 мс), это не видео 60 FPS. Действия с исходной страницей выполняются в её приложении.
- **Очистить**: останавливает наблюдение и удаляет текущие снимки и ответы из интерфейса. Скопированный вами ответ остаётся в системном буфере обмена.

## Разрешения macOS

В **Системные настройки → Конфиденциальность и безопасность**:

- **Запись экрана / Запись экрана и системного аудио**: разрешите ScreenStudy. Само приложение аудио не записывает. После изменения перезапустите его.
- **Универсальный доступ**: разрешите ScreenStudy, если хотите автоматическую вставку. Для обычного копирования это разрешение не нужно.

Названия разделов немного отличаются между версиями macOS. Если запускаете исходный main.py из Терминала вместо собранного приложения, разрешение может относиться к Python/Терминалу. Предпочтителен запуск ScreenStudy.app. После пересборки macOS иногда требует выдать разрешения повторно.

## Если что-то не работает

| Что произошло | Что проверить |
|---|---|
| Ollama не отвечает | Откройте Ollama; выполните `ollama list`; проверьте адрес и точное имя установленной модели. |
| Первый ответ долгий | Для Ollama первая загрузка модели занимает время. Выделите один вопрос. Таймаут быстрого Groq — 45 с, остальных режимов — 150 с. |
| Снимок не разрешён / пустой | Разрешите запись экрана и полностью перезапустите ScreenStudy. Некоторые защищённые окна недоступны для захвата. |
| Постоянно «экран изменился» | Выберите меньшую область без часов, анимации и видео. Для движущегося содержимого сделайте разовый запрос на неподвижной странице. |
| Ответ есть, меток нет | Метки показываются при наблюдении или закреплении вопроса, если включена настройка и положение строк надёжно сопоставлено. При прокрутке они временно скрываются; карточка ответа остаётся. |
| После прокрутки показывается прежний ответ | Он специально сохранён до готовности нового ответа и помечен как предыдущий. Для сохранения на любое время нажмите «Закрепить вопрос». |
| Ошибка 400 | Проверьте поддержку изображений и название модели. Попробуйте текстовый режим. |
| Ошибка 401 / 403 | Проверьте API-ключ и доступ к модели. |
| Ошибка 404 | Проверьте адрес API; в Ollama сначала загрузите модель. |
| Ошибка 429 | Проверьте лимиты/баланс провайдера, увеличьте интервал. Наблюдение после ошибки нужно включить снова. |
| Не вставляется текст | Разрешите «Универсальный доступ», выберите поле до конца отсчёта; при необходимости используйте ⌘V вручную. Некоторые приложения блокируют синтетические нажатия. |
| Окно захватывает само себя | В штатном режиме ScreenCaptureKit исключает окна ScreenStudy. Если это не происходит, остановите наблюдение и сообщите версию macOS. |

В облачном режиме содержимое выбранной области передаётся указанному сервису. Снимки и история вопросов не записываются приложением на диск. Политика хранения у облачного провайдера задаётся этим провайдером. Настройки сохраняются в `~/Library/Application Support/ScreenStudy/settings.json`.

## Что проверено

Основная логика, интерфейс, формирование запросов, обработка ответов и подключение ChatGPT проверены в Linux: **120 автоматических тестов**, запуск интерфейса и визуальная проверка его окон. Сетевые тесты используют локальные имитаторы, а не настоящую модель или аккаунт OpenAI. Синтаксис Python и установочных скриптов проверен.

Переключение закрепления, сохранение режима при повторном открытии и сворачивание проверены в Qt offscreen. Порядок окон и сворачивание в Dock требуют проверки на реальном Mac.

**Захват ScreenCaptureKit, OCR Vision, системные разрешения, метки поверх окон, Связка ключей, автоматическая вставка, сборка .app и запуск на M5 в этой среде не проверены.** В установщике есть дополнительная проверка доступности API macOS. Точность настоящей ИИ не измерялась. Это версия 1.3.0 для проверки на вашем Mac, не подписанный и нотарифицированный заранее установщик.

После установки проверьте на простом задании: «Сколько будет 2 + 2?» с вариантами 3/4/5. Подвигайте мышью по вариантам и откройте объяснение. Закрепите вопрос, прокрутите страницу: карточка должна сохраниться, метки — скрыться. Нажмите «Следующий вопрос» и проверьте замену карточки после готовности нового ответа. Вставку сначала проверьте в пустом документе TextEdit.

## Разработка

Python 3.10–3.13; PySide6 6.8.3; PyObjC 12.2.2. Код платформы изолирован в screenstudy/native.py. Обработка схемы и устаревших результатов находится в core.py, работа с ИИ — в ai.py.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py --demo
python -m unittest discover -s tests -v
```

`--demo` показывает явно помеченные примеры интерфейса, не подключаясь к ИИ и не захватывая экран. Для реального использования на Mac запускайте без этого аргумента или используйте собранный .app.
