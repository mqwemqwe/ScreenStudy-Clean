Вопрос на экране.
Ответ и объяснение рядом.

Версия 1.3.0 · MacBook M5 · macOS 14+ · ChatGPT, Groq или локальная ИИ

1. Установите приложение

  1. Закройте старую ScreenStudy через ⌘Q. Откройте INSTALL.command из распакованной папки.
  2. Если система не открывает файл: в Терминале напишите bash с пробелом, перетащите туда INSTALL.command и нажмите Enter.
  3. Если установщик попросит Python — установите Python 3.13 для macOS universal2 с python.org и повторите установку.
  4. После сборки откроется ScreenStudy. В дальнейшем запускайте его из домашней папки → Applications или через START.command.

Архив содержит проект и установщик. Готовое приложение собирается на вашем Mac. При установке нужен интернет.

Новое: ваша подписка ChatGPT

2. Войдите через ChatGPT

  1. Нажмите ⚙ → Режим → ChatGPT · моя подписка.
  2. Откройте Войти через ChatGPT / выбрать модель → Continue with ChatGPT.
  3. В браузере войдите в аккаунт с подходящей подпиской и разрешите ScreenStudy использовать её. Вернитесь в приложение.
  4. Выберите модель из загруженного списка → Использовать подписку.
  5. Нажмите Проверить подключение, затем Сохранить. Проверка использует один короткий запрос по подписке.

Ответы расходуют доступный объём подписки или кредитов. Доступность определяется OpenAI для выбранного аккаунта. Кнопка «Использование ChatGPT» открывает управление лимитами.

Для скорости выделяйте один вопрос. Для обычного текста оставьте изображение выключенным; для формул и рисунков включите его и выберите модель с поддержкой изображений. Объяснение запрашивается отдельно по i.

Groq, локальная Ollama и другие API сохранены. Инструкция — в README_RU.md.

3. Откройте задание

  1. Нажмите «Область…» и разрешите запись экрана в настройках macOS. После выдачи разрешения перезапустите приложение.
  2. Выделите вопрос вместе с вариантами и рисунками. Нажмите Enter, затем «Наблюдать».
  3. Ответ появится в боковой карточке. Кнопка i открывает объяснение. Галочки обозначают рекомендованные варианты.
  4. Закрепить вопрос сохраняет ответ и останавливает автоматические запросы новых заданий. Следующий вопрос → возобновляет наблюдение. При движении мыши и прокрутке карточка остаётся доступной; метки на странице могут временно скрываться.
  5. Для вставки нажмите «Вставить · 3 с» и за три секунды выберите нужное поле. Разрешите «Универсальный доступ» либо используйте обычное копирование и ⌘V.
  6. Кнопка «Открепить / Закрепить поверх приложений» меняет режим главного окна и запоминает выбор. «Свернуть» сворачивает окно; вернуть его можно через Dock. Наблюдение продолжится, пока вы не нажмёте «Пауза».

Для начала проверьте простое задание «2 + 2» и вставку в TextEdit. Ответы ИИ могут быть ошибочными.

120 тестов прошли в Linux. Вход, обновление сеанса и ответы ChatGPT проверены на локальных имитаторах. Реальная авторизация OpenAI, доступность подписки вашего аккаунта, ответы модели, захват экрана, OCR и сборка .app требуют проверки на Mac. Скорость настоящей модели здесь не измерялась. В облачном режиме выбранная область или её текст передаётся провайдеру.

Сопоставление и ключевые слова

Выделите задание целиком, включая обе колонки или все абзацы. Для сопоставления появятся пары что перенести → куда. Для выбора слов — точные фразы по абзацам. Значок i объясняет решение.

Номера связывают строки экрана с ответом в карточке. Перетаскивайте карточки и выбирайте слова вручную. Нажмите Закрепить вопрос, чтобы сохранить ответ на время работы.

Пример интерфейса. Это демонстрационные вопросы, не результат захвата вашего экрана.

Основные кнопки

Наблюдать — автоматические ответы при смене задания.

Ответить сейчас — разовый запрос.

Закрепить вопрос / Следующий вопрос — сохранить ответ или продолжить наблюдение.

Переписать — изменить формулировку.

Показать экран — расширить окно и включить просмотр.

Пауза — остановить новые снимки и запросы.
